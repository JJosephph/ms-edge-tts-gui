# Edge TTS 语音合成助手 v1.4.0：把普通配音、逐页配音、逐行配音一次做好

市面上的 TTS 工具很多，但真正适合视频旁白和批量配音的工具，关键不只是“能不能把文字读出来”，而是能不能把后面的工作一起做好：文稿怎么拆分、音频怎么对应、句子之间怎么停顿、字幕能不能直接用、批量文件能不能一次导出。

**Edge TTS 语音合成助手 v1.4.0** 是一个持续维护和更新的免费开源 Windows 桌面工具，基于 Microsoft Edge TTS，把这些实际使用中的问题集中解决了。

![普通模式：输入框直接生成全文音频](ui-v14-normal.png)

## 三种模式，按你的工作方式生成

**普通模式**适合最简单的全文配音。把文章、脚本或旁白粘贴到左侧输入框，点击生成即可得到一个完整音频，不要求分页，也不会因为普通换行就强制拆成多个文件。

**逐页模式**适合章节、镜头和分段文稿。导入 TXT、Markdown、DOCX 或 PDF，在 TXT 中用单独一行的 `[分页]` 标记分隔内容，每一页生成一个独立音频。导入后可以逐页检查、修改，再批量生成。

![逐页模式：导入文件并按分页生成音频](ui-v14-page.png)

**逐行模式**适合影视解说、短视频旁白和字幕脚本。导入 TXT 或直接粘贴文本后按行准备，每个非空行生成一个独立音频，空行自动忽略。无论是 20 行、100 行还是 200 行，都可以按顺序批量生成并导出。

![逐行模式：每个非空行生成一个独立音频](ui-v14-line.png)

## 句间停顿，不改变人声语速

很多时候需要的不是让人声变慢，而是让一句话和下一句话之间多停一会儿。v1.4.0 增加了独立的句间停顿设置，可以精确到毫秒调整静音间隔，不影响人声本身的朗读速度。音频时长、时间轴和字幕时间会同步更新，后期剪辑更容易对齐。

## 自动生成匹配音频的 SRT 字幕

开启“生成 SRT 字幕”后，每个句子都会对应一条字幕。字幕时间严格匹配最终合成音频，也会包含你设置的句间停顿，不需要再手工估算时间或重新切字幕。对于影视解说、课程旁白和短视频制作，这一步可以省下大量后期时间。

## 时间轴 JSON 与逐句试听高亮

开启时间轴功能后，保存时可以同时得到 MP3 和同名时间轴 JSON，记录每句话的开始与结束时间。点击试听时，正在播放的句子会在原文中实时高亮，适合字幕对齐、语言跟读、逐句复习和剪辑定位。

## 批量导出，直接进入后期制作

逐页和逐行生成完成后，可以一键导出 ZIP。压缩包中会按顺序保存独立音频，并可包含对应的 SRT、时间轴 JSON 和批量清单。软件还提供示例 TXT，第一次使用时不需要猜分页或逐行格式。
